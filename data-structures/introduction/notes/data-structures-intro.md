# Data Structure
Is a collection of values. Yhe values can have relationships among them, and they can have functions apply to them.  
Think od a data structure as ny sort of compartment or container.  
Each of these containers are specific for it's own thing.  

## Operations in data structures
- **Insertion:** Add a new data item in a given collection of items.
- **Deletion:** delete data.
- **Traversal:** Access each data item exactly once so that it can be processed.
- **Searching:** Find out the location of the data item if it exists in a given collection.
- **Sorting:** Having data that is sorted.
- **Access:** How do we access each data that it's on our computer.
